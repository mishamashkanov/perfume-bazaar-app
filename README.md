# Парфюмерный базар

Консольное приложение на C++ для парфюмерного базара. Маклеры заключают сделки, управляющий формирует отчёты.

## Установка и сборка
```bash
git clone <ссылка>
cd perfume-bazaar-app
mkdir build && cd build
cmake ..
make
```

## Использование
./perfume_bazaar
